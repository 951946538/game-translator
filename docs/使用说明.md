# 使用说明

## 首次使用

1. **安装依赖**（一次性）：

```powershell
cd j:\项目文件\game-translator
py -V:3.12 -m venv .venv
.venv\Scripts\pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```

2. **准备本地翻译模型**（可选，使用 Ollama 后端时需要）：

```powershell
ollama pull qwen2.5:7b
```

3. **启动工具**：

```powershell
.venv\Scripts\python main.py
```

## 翻译游戏

1. 启动英文游戏（窗口或全屏均可）
2. 两种监控方式：
   - **全屏模式**：按 **F7**，直接监控整个主屏，翻译画面中所有英文文本。适合全屏游戏。
   - **框选区域**：按 **F8** → 屏幕变暗 → 在游戏文本位置**拖动框选**。速度更快、更精准。
3. 译文自动出现在悬浮窗，可按住拖到不挡视野的位置

> **全屏游戏注意**：请在游戏设置中把显示模式改为**无边框窗口（Borderless）**。
> "真独占全屏"模式下 GDI 截屏可能得到黑屏；无边框窗口画面效果相同且截屏正常。

## 热键速查

| 热键 | 功能 |
|------|------|
| F7 | 全屏模式（监控整个主屏） |
| F8 | 重新框选监控区域 |
| F9 | 暂停 / 恢复监控 |
| F10 | 切换翻译后端（ollama → llm → deepl） |

## 配置云翻译（可选）

编辑 `config.json`：

**LLM 云 API**（DeepSeek 示例，到 platform.deepseek.com 申请 Key）：

```json
"llm": {
  "base_url": "https://api.deepseek.com/v1",
  "api_key": "sk-xxx",
  "model": "deepseek-chat"
}
```

**DeepL**（到 deepl.com/pro#developer 申请免费 Key，以 `:fx` 结尾）：

```json
"deepl": { "api_key": "xxx:fx" }
```

## 灵敏度调优

| 现象 | 调整 |
|------|------|
| 游戏轻微动画就触发翻译 | 调大 `diff_threshold`（如 6~10） |
| 文字变了却没触发 | 调小 `diff_threshold`（如 2） |
| 翻译太慢跟不上对话 | 调小 `stable_ms`（如 300） |
| 转场动画频繁误触发 | 调大 `stable_ms`（如 800） |

## 常见问题

- **首次识别慢**：PaddleOCR 模型首次加载需 10~30 秒，之后秒出
- **识别不准**：框选区域尽量只包含文字，避开复杂背景；游戏字体艺术性太强时可框大一点
- **Ollama 翻译失败**：确认 `ollama serve` 在运行、模型名与 `config.json` 中一致
- **CPU 占用高**：PaddleOCR 用 CPU 推理属正常，暂停（F9）可立即降低
